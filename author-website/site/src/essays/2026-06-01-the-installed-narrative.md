This is a placeholder essay. It exists only to demonstrate the reading page: the serif body, the capped measure, the spacing built for long-form prose.

When you add a real essay, drop a Markdown file into `src/essays/` with a `title`, a `date`, and a one-line `standfirst`. The index page lists them newest-first, and each gets its own reading page automatically.

The body is ordinary Markdown — paragraphs, subheads, emphasis — set in the same type system as the rest of the site, so an essay reads as part of the work rather than a bolt-on blog.
